# Система та модель даних публічної бібліотеки

Базова концептуальна модель системи публічної бібліотеки, яка має зберігати та вести облік наявних видань, фізичних примірників видань, дозволяє видавати та фіксувати факт видачі примірників на руки.

## Що входить

До системи входить каталог книг, баланс примірників, інформація про читачів, фіксація видачі та повернення примірників книг.

## Що не входить

До системи не входить робота з онлайн середовищем, закупівля книг, робота з фінансами.
