# Специфікація моделі даних публічної міської бібліотеки

## Мета

Створити специфікацію для моделі даних публічної міської біблотеки, що фіксує сутності, атрибути, зв'язки, обемеження та критерії готовності

## Сутності та атрибути

### Читач
- id {PK, string} - ідентифікатор читача
- telNo {AK, string} - номер телефона читача
- fullName {string} - ПІБ читача

### Видання
- id {PK, string} - ідентифікатор видання
- ISBN {string, AK} - стандартний міжнародний ідентифікатор видання
- title {string} - назва видання
- publicationYear {int} - дата створення видання
- amount {int, похідний} - кількість наявних примірників

### Автор
- id {PK, string} - ідентифікатор автора
- fullName {string} - ПІБ автора
- pseudonym {string, опціональний} - псевдоним автора

### Примірник
- id {PK, string} - ідентифкатор примірника
- condition {enum[good, normal, bad]} - стан примірника

### Видача (асоціативна сутність)
- id {PK, string} - ідентифікатор видачі
- issueDate {string} - дата початку видача примірника
- issueEndDate {string} - дата кінця видача примірника
- isOverdue {bool, похідний} - чи прострочено оренду
- closedDate {string, опціональний} - дата повернення примірника та закінчення видачі.
- finalCondition {enum[good, normal, bad], опціональний} - стан примірника на момент повернення

## Зв'язки та сутності

- Видання < - > Примірник: Кожне видання може не мати або мати певну кількість примірників (0..*). Кожен примірник відноситья до одного видання (1..1)
- Читач < - > Видача: Кожен читач може мати кілька видач або не мати жодної (0..*). Кожна  видача повинна бути прив'язана до конкретного читача (1..1)
- Примірник < - > Видача: Кожна видача прив'язана до конкретного примірника (1..1). Кожен примірник може мати зв'язки с декількома видачами або не мати жодної (0..*)
- Автор < - > Видання: кожен автор може написати багато видань або не написати жодного (0..*). Кожне видання може мати від одного до декількох авторів (1..*)

## Обмеження

- Кожен читач може одночасно мати примірники у кількості N, але виключно по одному примірнику на видання
- Кожен примірник може мати N зв'язків із екземплярами видачі, але не більше одної активної видачі одночасно. Видача вважається активною, доки closedDate не заповнено
- Атрибут finalCondition у сутності Видача може бути заповнений лише тоді, коли заповнено closedDate

## Критерії прийняття

- Усі типи атрибутів узгоджені
- Уся модель нормалізована під 3NF
- Відсутні сполучні таблиці
