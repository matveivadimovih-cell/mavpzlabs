# Специфікація моделі даних публічної міської бібліотеки

## Мета

Створити специфікацію для моделі даних публічної міської біблотеки, що фіксує сутності, атрибути, зв'язки, обемеження та критерії готовності

## Сутності та атрибути

### Читач
- id {PK, string} - ідентифікатор читача
- telNo {AK, string} - номер телефона читача
- fullName {string} - ПІБ читача

### Видання
- id {PK, string} - ідентифікатор видання
- title {string} - назва видання
- amount {int, похідний} - кількість наявних примірників

### Примірник
- id {PK, string} - ідентифкатор примірника

### Видача (асоціативна сутність)

## Зв'язки та сутності

- Видання < - > Примірник: Кожне видання може не мати або мати певну кількість примірників (0..*). Кожен примірник відноситья до одного видання (1..1)
- Читач < - > Видача:
- Примірник < - > Видача:

## Обмеження

- Кожен читач може одночасно мати примірники у кількості N, але виключно по одному примірнику на видання 

## Критерії прийняття

- Усі типи атрибутів узгоджені
- Уся модель нормалізована під 3NF
- Відсутні сполучні таблиці
